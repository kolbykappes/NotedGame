# Noted project profile

The one place the portable Unity kit looks for project facts. Keep it short and factual; update it when a fact changes.

## Identity

- A first-person Windows game (Steam), one Editor normally open. Working title "Noted: I Understand Your Frustration".
- Working scenes: **`Assets/Scenes/Facility.unity`** (the MVP, generated by `Noted.EditorTools.FacilityBuilder.Build()`; rebuilding wipes hand-edits to it), `Assets/Scenes/Greybox.unity` (the movement test room, built by `tools/build_greybox.cs`) and the unused template `Assets/Scenes/SampleScene.unity`.
- Design docs (in this repository): `ClickOne/Docs/concept/sabotage-spine.md` (current story and core loop), `ClickOne/Docs/concept/hold-the-line.md` (earlier concept, six-beat loop spine, candidates) and `ClickOne/Docs/competitive/` (research).

## Versions (re-check if stale)

Unity 6000.6.6f1, URP 17.6.0 (template `com.unity.template.urp-blank`), Input System 1.20.0, uGUI 2.6.0, Test Framework 1.4.6,
Unity CLI 1.0.0-beta.13, `com.unity.pipeline` 0.8.0-exp.1 (installed 2026-10-24 with `unity pipeline install --package-version 0.8.0-exp.1`, with the owner's approval).

## Paths and layout

- Unity project root: `C:\Code\Noted` (a git repository on `main`; the project root is also the checkout root).
- Project code: `Assets/Scripts/Core/` (plain C#, no engine references) and `Assets/Scripts/Game/` (MonoBehaviours). Editor tooling: `Assets/Editor/` (assembly `Noted.Editor`: `FacilityBuilder`, `OffscreenCapture`). Materials made by the builder: `Assets/Materials/Noted_*.mat`. Scratch scripts: `tools/` (outside `Assets/`). Prefabs: `Assets/Prefabs/`. Tests: `Assets/Tests/EditMode/`.
- Assembly definitions: `Noted.Core` (no references, `noEngineReferences`; game rules and math), `Noted.Game` (references `Noted.Core` and `Unity.InputSystem`), `Noted.Core.Tests` (Editor-only Edit Mode tests; references `Noted.Core` and the test runner assemblies).
- Third-party content to leave untouched: `Assets/TutorialInfo/`, `Assets/Readme.asset` (template files; may be deleted with approval).

## Editor settings that matter

- Enter Play Mode options: **domain reload off, scene reload on** (`m_EnterPlayModeOptions: 1`). Kit rule 9 applies: no mutable statics without a reset hook.
- Run In Background (`PlayerSettings.runInBackground`): **off** (saved value). Kit rules 3a and 38: turn it on only for a Play Mode check with the Editor in the background, and restore it to off before `editor_stop`. Helpers: `tools/play_helpers.ps1` (`PlayBegin`, `PlayEnd`, `Snap`).

## Protected (approval and a stated plan first), beyond the kit defaults

None beyond the kit defaults. The template's `Assets/Settings/` render-pipeline assets are covered by the render-pipeline rule.

## Helpers

- Off-screen render helper: `Noted.EditorTools.OffscreenCapture` (`FromPose`, `Render`; borrows overlay canvases so UI appears). Drive and probe the running game: `tools/probe.cs`, `tools/play_helpers.ps1`, `tools/play_full.ps1`. See `.claude/project/lessons.md`.
